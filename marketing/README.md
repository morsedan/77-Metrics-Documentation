# Marketing

Marketing copy and strategy for 77 Metrics. This directory is **not** included in the MkDocs build — it exists only in the repository for reference and editing.

All files in this directory are public. Do not commit credentials, private business plans, or personally identifiable information.

---

## Contents

### Strategy and guidelines

| File | Purpose |
|------|---------|
| [`positioning.md`](positioning.md) | Target audience, key differentiators, message hierarchy, tone, and claims to avoid |
| [`guidelines.md`](guidelines.md) | Terminology, in-app label reference, voice guidance, screenshot naming conventions |

### App Store

| File | Purpose |
|------|---------|
| [`app-store/listing.md`](app-store/listing.md) | Subtitle, promotional text, full description, keywords, What's New, and screenshot plan |

### Website (draft copy)

Copy for a possible future marketing website. Do not publish until a production URL is configured and the App Store listing is live.

| File | Purpose |
|------|---------|
| [`website/landing.md`](website/landing.md) | Headline, subheadline, feature highlights, and call to action |
| [`website/features.md`](website/features.md) | Full feature-by-feature descriptions |
| [`website/faq.md`](website/faq.md) | Short FAQ aimed at potential customers |

## Screenshots

Screenshot assets live in `/screenshots/` at the repository root and are shared between marketing and the help site.

| Path | Contents |
|------|----------|
| `screenshots/app-store/` | App Store submission screenshots |
| `screenshots/website/` | Website hero and feature images |
| `screenshots/docs/` | In-documentation screenshots for the help site |

See `guidelines.md` for screenshot naming conventions and capture guidelines.
