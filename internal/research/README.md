# Research

App audit notes and feature investigation for 77 Metrics documentation.

## Purpose

This folder holds notes from reading the app source code — behavior details, edge cases, and implementation specifics that inform the help content in `docs/`.

These notes are internal working material. Verified findings move into the public documentation; speculative or incomplete notes stay here.

## Audit scope

The app audit will cover:

- All 21 metric behaviors and their exact calculation logic
- Dashboard page and tile system (sizes, reflow, enhanced information)
- Drive lifecycle (start, pause, resume, continue, stop, recover)
- Trip history and trip groups
- Widget and Live Activity behavior
- CarPlay features and limitations
- Settings (units, display precision, driving reminder)
- Export format and data structure
