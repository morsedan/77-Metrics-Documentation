# Internal

Research notes, app audit findings, and documentation planning materials.

This directory is **not** included in the MkDocs build and will not appear on the public help site.

## Contents

| Path | Purpose |
|------|---------|
| `research/` | App audit notes, metric behavior research, and feature investigation |

## App audit

The app audit documents what each feature and metric actually does, based on reading the app source code. It is the source of truth for documentation content and precedes all public-facing content work.

See `research/` for audit notes as they are created.
