# 77 Metrics

77 Metrics turns your iPhone into a real-time GPS vehicle dashboard. It displays live speed, elevation, distance, G-force, and 17 other metrics on a fully customizable tile grid while you drive, then saves a complete record of each drive for later review.

- No account required — all data stays on your device
- Works entirely offline — GPS does not need a cellular or Wi-Fi connection
- 21 configurable metrics across up to 12 tiles per page
- Barometric and GPS altitude fusion for accurate elevation data

## Metric reference

77 Metrics provides 21 metrics across seven categories. Each tile on the dashboard shows one metric; a page can hold up to 12 tiles.

- [All metrics — complete table](docs/metrics/index.md)

Individual category pages:

| Category | Metrics |
|----------|---------|
| [Speed](docs/metrics/speed.md) | Speed, Average Speed, Moving Avg, Max Speed, Vertical Speed |
| [Distance](docs/metrics/distance.md) | Distance, Trip Distance |
| [Elevation](docs/metrics/elevation.md) | Altitude, Grade, Elevation Gain, Elevation Loss, Net Elevation, Elevation Profile |
| [Time](docs/metrics/time.md) | Elapsed Time, Moving Time, Stopped Time |
| [Navigation](docs/metrics/navigation.md) | Heading, Direction |
| [G-Force](docs/metrics/g-force.md) | G-Force, Max G |
