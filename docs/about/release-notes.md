## Version 1.2

*In progress*

Changes in this release include:

- Dashboard tiles: seven resize levels with automatic reflow
- Enhanced information mode per dashboard page
- Pause and resume an active drive
- Continue a previously saved drive as a new segment
- Interrupted drive recovery on launch
- Trip Distance tile (resettable odometer)
- Trip groups: combine related drives
- Home screen widgets with Live Activities
- CarPlay support
