# Widgets

77 Metrics provides three widget placements and a Live Activity. All can be configured independently to show the metrics most useful to you at a glance.

## Available widget placements

| Placement | Size | Where it appears |
|-----------|------|-----------------|
| Home screen | Small | iPhone Home Screen |
| Lock Screen circular | Circular accessory | iPhone Lock Screen |
| Lock Screen rectangular | Rectangular accessory | iPhone Lock Screen |

Each placement supports 1 or 2 configurable metric slots. Configure which metrics appear in **Settings → CarPlay & Widgets**.

## Adding widgets

**Home screen:** Long-press the Home Screen, tap the **+** button, search for **77 Metrics**, and add the widget.

**Lock Screen:** Long-press the Lock Screen, tap **Customize**, select the Lock Screen, and add a 77 Metrics widget from the widget row below the clock.

## What each widget shows

### Home screen widget (small)

**When idle:** A "Start Drive" button. Tapping it launches 77 Metrics directly into an active drive.

**When a drive is active:** A red recording dot, the current value of your configured metric, and a "Tap to open" label that links to the app. Shows 1 metric.

**When location access is denied:** An orange location icon with "Location Required." Tap to open app settings.

### Lock Screen circular widget

**When idle:** A record button icon. Tapping it starts a drive.

**When a drive is active:** The current value and short label of your configured metric. Shows 1 metric.

### Lock Screen rectangular widget

**When idle:** A "Start Drive" icon and label. Tapping it starts a drive.

**When a drive is active:** The current values of up to 2 configured metrics, each with its short label and unit. The top row shows a red recording dot. Shows up to 2 metrics.

## Widget updates

Widgets refresh automatically:
- Immediately when a drive starts or stops
- Approximately every 1 km during an active drive
- At most every 15 minutes as a background fallback

Widgets do not update in real time between these events. For live metric data, open the app.

## Live Activities

When a drive is active, 77 Metrics shows a **Live Activity** on the Lock Screen and in the Dynamic Island (on supported iPhone models).

The Live Activity displays up to 2 configurable metrics. Configure which metrics appear in **Settings → CarPlay & Widgets → Live Activity**.

**While recording:** Both metrics update approximately once per second.

**While paused:** Metrics show their last recorded values and a "Paused" indicator appears.

**When the drive stops:** The Live Activity ends and is dismissed automatically.

Live Activities require iOS 16.1 or later and must be enabled in iOS Settings → 77 Metrics → Live Activities.

## Configuring widget metrics

Open **Settings → CarPlay & Widgets** and tap the widget or Live Activity you want to configure. Each surface shows the configurable metric slots. Tap any slot to change the metric. Some metrics are not available on all surfaces (for example, Elevation Profile is not available on any widget surface).

The default metrics for each surface at first launch are Speed for the home screen and circular widgets; Speed and Distance for the rectangular widget and Live Activity.
