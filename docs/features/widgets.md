# Widgets

77 Metrics provides home screen and Lock Screen widgets that show key metrics and drive status at a glance.

## Available widgets

Widgets show a snapshot of current drive state: active or idle, current speed, and recent distance. During an active drive, widgets update more frequently using iOS Live Activities.

## Adding widgets

Long-press the home screen or Lock Screen and tap the **+** button to add a widget. Search for **77 Metrics** and choose a widget size.

## Live Activities

When a drive is active, 77 Metrics can display a Live Activity on the Lock Screen and Dynamic Island showing real-time speed and drive status. Live Activities update in near-real time via the system and stop when the drive is stopped.

## Starting a drive from a widget

The drive widget includes a **Start Drive** button that launches 77 Metrics directly into an active drive, skipping the main dashboard.

## Widget refresh

WidgetKit widgets update on iOS's schedule outside of an active drive. If a widget appears stale after saving a drive, editing and saving the home screen layout prompts a refresh.
