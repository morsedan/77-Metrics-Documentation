# Features

77 Metrics is built around five main areas.

| Feature | Description |
|---------|-------------|
| [Dashboard](dashboard.md) | Customizable multi-page display of live metrics while driving |
| [Recording Drives](drives.md) | Start, pause, resume, and save GPS drive recordings |
| [Trips & History](trips.md) | Review saved drives, group related drives into trips, and export data |
| [Widgets](widgets.md) | Home screen and Lock Screen widgets that update during active drives |
| [CarPlay](carplay.md) | Dashboard and drive controls on your car's built-in display |
