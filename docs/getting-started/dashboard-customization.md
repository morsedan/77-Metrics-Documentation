# Dashboard customization

The 77 Metrics dashboard is fully customizable. You can choose which metrics appear, how large each tile is, how tiles are arranged, and how many pages you have.

## Open the edit view

Tap the edit button (top-right of the dashboard) to enter edit mode. Changes take effect immediately and are saved automatically.

## Add and remove metrics

In edit mode, tap any tile to change the metric it displays. A picker lists all 21 available metrics. Tap outside the picker to dismiss without changing.

To remove a tile, tap the remove button on the tile. To add a tile, tap **Add Metric** at the bottom of the edit view.

Each page can hold between 1 and 12 tiles. A metric can only appear once per page.

## Resize tiles

Tiles come in seven sizes (Size 1 through Size 7). Larger tiles give metrics more visual space and unlock additional context in Enhanced Information mode.

| Size | Portrait grid | Landscape grid |
|------|--------------|---------------|
| 1 | 1 × 1 | 1 × 1 |
| 2 | 1 × 2 | 2 × 1 |
| 3 | 2 × 2 | 2 × 2 |
| 4 | 2 × 3 | 3 × 2 |
| 5 | 2 × 4 | 4 × 2 |
| 6 | 2 × 5 | 3 × 3 |
| 7 | 2 × 6 | 4 × 3 |

The portrait grid is 2 columns × 6 rows. The landscape grid is 4 columns × 3 rows.

When you resize a tile, other tiles reflow automatically. If a tile cannot fit at its current size, it shrinks to the largest size that fits. Tiles that cannot fit at any size are temporarily displaced and return when space becomes available.

## Rearrange tiles

Drag tiles to reposition them on the grid. A larger tile can displace smaller tiles, which then reflow into available space. A smaller tile cannot displace a larger one — it snaps back to its original position.

## Manage pages

Swipe left or right on the dashboard to switch between pages. In edit mode you can:

- **Add a page** — creates a new page with the default tile set
- **Delete a page** — removes the page (at least one page must remain)
- **Rename a page** — optional name shown as the page tab label
- **Reorder pages** — drag to change page order

## Enhanced information mode

Each page has an optional **Enhanced Information** toggle. When enabled, tiles at Size 2 and larger display additional context alongside their primary value — for example, an Average Speed tile at Size 2 or larger shows how your current speed compares to the average, and the direction tile at larger sizes shows your recent travel path on a mini map.

## Settings

**Units** and **Display Precision** apply globally to all pages. Access them from the edit view.

- **Units:** Imperial (mph, ft, mi) or Metric (km/h, m, km)
- **Display Precision:** Number of decimal places shown on metric values (default: 1)
