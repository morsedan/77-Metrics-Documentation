# 77 Metrics Help

77 Metrics is a GPS dashboard for iPhone that shows the data you care about while you drive. Choose from 21 metrics, arrange them across multiple customizable dashboard pages, and review your complete drive history.

## Quick navigation

**New to 77 Metrics?** Start with [Getting Started](getting-started/index.md) to install the app and record your first drive.

**Looking for a specific metric?** See the [Metric Reference](metrics/index.md) for every metric explained in detail.

**Customizing your dashboard?** The [Dashboard guide](features/dashboard.md) covers pages, tiles, sizes, and layout.

**Something not working?** Check the [FAQ](faq.md) or [Troubleshooting](troubleshooting.md).
