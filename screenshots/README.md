# Screenshots

Screenshot assets for the 77 Metrics help site and marketing materials.

## Directory structure

```
screenshots/
  docs/          Screenshots used in help documentation
  app-store/     App Store submission screenshots
  website/       Website marketing screenshots
```

## Naming convention

Use descriptive, lowercase, hyphen-separated names that describe the content:

```
dashboard-portrait-default.png
dashboard-landscape-speed-page.png
drive-complete-overview.png
drive-complete-elevation.png
trip-history-list.png
widget-home-screen.png
carplay-dashboard.png
```

## Referencing in docs

From a file in `docs/features/`, reference a screenshot with a relative path:

```markdown
![Default dashboard](../../screenshots/docs/dashboard-portrait-default.png)
```
